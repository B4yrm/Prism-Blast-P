# Fonts

These fonts are embedded in the game so it works offline on Android. Together they cover every Azerbaijani letter: Ə ə Ğ ğ I ı İ i Ş ş Ç ç Ö ö Ü ü.

| Font | Use | Licence | Source |
|---|---|---|---|
| Baloo 2, weight 800 | Headings and numbers | SIL OFL 1.1 (`OFL-Baloo2.txt`) | npm `@fontsource/baloo-2` |
| Nunito, weights 800 and 900 | Body text | SIL OFL 1.1 (`OFL-Nunito.txt`) | npm `@fontsource/nunito` |
