# Fishing Tycoon art pipeline

All world art (buildings, boats, people, props, ground tiles) comes from **sprite atlases** in `assets/atlas/`. The game code only knows **frame names**. To swap the art, replace the atlas files and rebuild. No code changes are needed.

## Where the atlases come from

`tools/bake/` renders 3D models into isometric sprites in headless Chromium (three.js):

- **CC0 models** from Kenney's *Starter Kit City Builder* (`assets/kenney/`, see `assets/kenney/LICENSE.md`): road, pavement and fountain tiles, and forest tiles.
- **Own models** (`tools/bake/buildings.js`, `units.js`, `kit.js`): fishing buildings with 3 tiers each, boats, workers and customers, cranes, lighthouse, containers, trees and props. They are built in the same flat low-poly cartoon style.

Every sprite gets the same 2:1 dimetric camera, warm sun from the upper left, soft drop shadows and a 2 px dark outline. That keeps the look consistent.

```bash
cd tycoon
node tools/bake/bake.mjs                      # re-bake assets/atlas/world-*.webp + .json
node tools/bake/bake.mjs preview b/ boat/     # PNG previews in .preview/ (filter by prefix)
npm run build                                 # inline atlases into index.html
```

## Atlas format (for artists or bought packs)

- **Format.** TexturePacker *JSON (Hash)* page plus a `.webp` or `.png` image with the same base name. Pages are at most 2048×2048.
- **Scale.** One map tile is **128 px wide** and 64 px tall (2:1). Set `meta.scale` to `2`.
- **Pivot.** Every frame needs a `pivot` (0–1). The pivot is the world point the sprite stands on:
  - buildings and ground tiles: the footprint corner with the smallest grid x/y (the top corner of the diamond);
  - boats: the hull centre at the waterline;
  - people and props: the feet or base centre.
- **Light and style.** Light comes from the upper left. Use a 2 px dark outline (`#1c2a3f`), saturated cartoon colours and no baked-in background.

## Frame names

| Name | Meaning |
|---|---|
| `b/<hq\|factory\|warehouse\|market\|harbor\|farm>/<tier>` | Building at tier 1–3. `factory/0` and `farm/0` are construction sites. |
| `b/<cafe\|shed\|icehouse>/1` | Decorative town buildings, 2.5×2.5 tiles |
| `boat/<class 0-2>/<dir>` | Boat class 0–2, dir 0:+x, 1:+y, 2:−x, 3:−y |
| `p/<worker\|c0..c5>/<none\|raw\|prod\|can\|bag>/<dir>/<step 0-3>` | Walk cycles |
| `prop/<name>` | crane, hook, lighthouse, buoy, fountain, lamp, bench_x/z, bush, flowers, rock, pallet_raw/prod, barrels, container_r/b, crate_raw/prod, cbox, cones, belt, belt_legs, tree0–5, car_<0-3>_<0\|1> |
| `t/<grass0-2\|pave\|quay\|pier\|cliffX\|cliffY>` | Ground tiles |
| `k/<kenney-model>/<rotation>` | Kenney road, pavement and forest tiles |

You can replace art one frame at a time. Put the new frames in an extra page, for example `assets/atlas/custom-0.json` with `.webp`. Pages load in alphabetical order, and a later page overrides frames with the same name.

## Licences

Add only assets whose licence allows commercial use and modification. Record each source in a `LICENSE.md` next to the files: URL, author, licence, date. Current third-party art: Kenney Starter Kit City Builder models (CC0 1.0). Everything else is generated by our own bake code.
