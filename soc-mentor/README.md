# 🛡️ SOC Mentor — 0-dan SOC Analitikə (Azərbaycanca)

İnteraktiv, oflayn işləyən öyrənmə proqramı — səni **sıfırdan** SOC (Security Operations Center) analitik səviyyəsinə aparır. Sistem, şəbəkə, red team / blue team, loglar, SIEM, forensika və daha çoxunu əhatə edir.

## Necə istifadə etməli

`soc-mentor/index.html` faylını istənilən müasir brauzerdə aç. Quraşdırma, internet və ya server lazım deyil — hər şey lokal işləyir. Proqres brauzerin yaddaşında (localStorage) saxlanır.

## Quruluş

Proqram 3 səviyyəyə bölünüb:

- **L1 — Junior SOC Analitik (11 modul):** kibertəhlükəsizlik əsasları, kompüter/OS, Windows, Linux, şəbəkə (OSI/TCP-IP, DNS, HTTP/TLS, email), təhdidlər & malware, kriptografiya, loglama & SIEM, alert triage, incident response əsasları. **Bu səviyyəni bitirəndə ilk SOC işinə müraciət edə bilərsən.**
- **L2 — SOC Analitik II / Incident Responder (7 modul):** paket analizi (Wireshark), Active Directory hücumları, Linux/web dərin təhlil, malware triage, threat intelligence, detection engineering (Sigma), IR playbook-ları & phishing.
- **L3 — Senior / Threat Hunter / DFIR (4 modul):** threat hunting, disk & yaddaş forensikası, malware reverse engineering, purple team & SOC idarəçiliyi.

**Cəmi:** 22 modul · 91 dərs · ~400 sual · 87 praktiki tapşırıq.

Hər modulda: 📘 **Nəzəriyyə** → ❓ **Suallar** (keçid balı 80%) → 🛠️ **Praktika** (real log/ssenari tapşırıqları). Hər səviyyənin sonunda **Yekun İmtahan** var.

Əlavələr: müsahibə sualları, ev laboratoriyası (homelab) bələdçisi, resurslar & sertifikatlar, port/Event ID arayış cədvəli, lüğət və tam mətn axtarışı.

## Etika

Buradakı bütün hücum texnikaları yalnız **öz laboratoriyanda və icazəli təlim platformalarında** (TryHackMe, PortSwigger, LetsDefend və s.) öyrənmək üçündür. İcazəsiz sistemə müdaxilə qanunla cəzalandırılır.
